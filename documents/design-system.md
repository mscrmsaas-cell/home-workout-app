# 居家锻炼APP - 设计系统文档

## 设计哲学（基于 Emil Kowalski + Apple Design）

### 核心原则
- **不可见的细节汇聚**: 每个微交互都经过精心设计，用户不会注意到它们，但会感受到整体的质感
- **物理正确性**: 动画遵循现实世界的物理规律，不使用突兀的变换
- **频率适配**: 高频操作（如切换标签）无动画或极简动画，低频操作（如完成锻炼）可有适度庆祝动画
- **可中断性**: 所有过渡动画都可在中途被打断并平滑重新定位

## 动画规范

### 缓动曲线
```css
--ease-out: cubic-bezier(0.23, 1, 0.32, 1);        /* 元素进出 */
--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);    /* 移动/变形 */
--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);     /* 抽屉/底部弹窗 */
--ease-spring: cubic-bezier(0.5, 1.8, 0.3, 0.8);   /* 弹性（仅低频） */
```

### 时长规范
| 场景 | 时长 | 说明 |
|------|------|------|
| 按钮按压 | 100-160ms | 快速反馈 |
| 列表项按压 | 200ms | 状态切换 |
| 弹窗出现 | 300-400ms | 内容进入 |
| 弹窗消失 | 200ms | 快速退出 |
| 页面切换 | 350ms | 导航过渡 |
| 抽屉展开 | 400-500ms | 使用ease-drawer |
| 倒计时数字 | 300ms | 数字变化 |
| 完成庆祝 | 800ms | 低频，可稍长 |

### 物理正确性规则
1. **从不scale(0)**: 元素进入从scale(0.95)+opacity:0开始
2. **弹窗原点**: 从触发点展开，transform-origin: center（全屏弹窗）
3. **可中断**: 使用CSS transitions而非keyframes，支持反向操作
4. **非对称**: 进入可稍慢（用户决定），退出必须快（系统响应）

### 频率适配
| 频率 | 决策 |
|------|------|
| 100+次/天（切换标签、计时器控制）| 无动画 |
| 数十次/天（列表项点击、展开折叠）| 减少或极简动画 |
| 偶尔（弹窗、抽屉）| 标准动画 |
| 罕见/首次（完成锻炼、成就解锁）| 可添加庆祝动画 |

### 弹簧动画（仅用于）
- 拖拽手势（带惯性）
- 完成庆祝的弹性反馈
- 参数：{ type: "spring", duration: 0.5, bounce: 0.2 }

## 可访问性

### 动态字体
- 支持系统级字体缩放（110%-200%）
- 最大字号时，标题降为28px，正文降为19px
- 布局必须支持文本换行和高度自适应

### 减少动态效果
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: opacity 0.2s ease !important;
  }
}
```
- 保留透明度/颜色过渡（辅助理解）
- 移除移动/位移动画
- 弹簧动画退化为线性过渡

### 触控区域
- 最小触控：44x44px（Apple HIG）
- 重要按钮：56x56px（本文档）
- 间距：12px 防止误触

## 手势交互

### 水平滑动（锻炼列表）
- 触发：水平滑动 > 50px
- 动量：速度 > 0.3px/ms 即可触发翻页
- 边界阻尼：超出内容区域时，移动距离减半（摩擦感）
- 动画：弹簧回弹或切换，400ms ease-out

### 垂直滑动（页面滚动）
- 标准滚动，带阻尼边缘
- 快速滑动惯性保留

### 长按（锻炼操作）
- 阈值：500ms
- 反馈：轻微缩放 pulse(0.97) + 震动
- 操作菜单从底部弹出（iOS风格）

## 锻炼流程专用规范

### 倒计时界面
- 大数字：96px，等宽字体（防止数字宽度变化抖动）
- 数字变化：cross-fade 300ms ease-out
- 进度环：圆环进度条，stroke-dashoffset动画，使用transition而非CSS动画
- 暂停/继续：图标切换，200ms过渡

### 休息间隔
- 背景色渐变：从锻炼色过渡到放松色（系统靛蓝）
- 呼吸指示：缩放动画 1.0→1.05→1.0，4s循环，ease-in-out
- 下一项预览：底部滑入，300ms ease-drawer

### 完成界面
- 庆祝动画：对勾图标缩放+旋转，800ms，spring(bounce:0.3)
- 统计数字：从0计数到目标，ease-out，1200ms
- 按钮延迟出现：300ms延迟，从底部滑入
- 彩带效果（可选）：低频场景，prefers-reduced-motion时禁用

### 计时器控制
- 高频操作：无动画
- 开始/暂停：图标立即切换，无过渡（100+次/天）
- 重置：确认后即时重置，无动画

## 实现备注

### 性能要求
- 仅使用 transform 和 opacity 做动画（GPU加速）
- 避免动画 width/height/margin/padding/top/left
- 使用will-change: transform 在动画元素上（动画结束后移除）
- 列表虚拟化：锻炼列表 > 50项时使用

### 三星S25 Ultra适配
- 屏幕：3120x1440，6.9英寸，120Hz刷新率
- 边缘：圆角屏幕，内容避开边缘34px
- 状态栏：高度估算32px（实际由系统提供）
- 底部导航栏：手势导航，底部安全区域24px
- 刷新率：动画支持120fps，时长相应缩短（300ms在60Hz=18帧，120Hz=36帧）
